LPSN discarded source citation text when constructing DOI/PMID nodes, and PREGO left BTO names blank even though a declared ontology input could supply them. This preserves unique LPSN citations as explicitly described display labels and hydrates emitted BTO classes from hash-bound SemSQL metadata with an admission audit. Conflicts and missing authority remain explicit; identifiers and source associations are preserved.

Real canaries preceded bounded replays: source citations cover 36,512 previously unnamed publication IDs, and retained BTO release2021-10-26 supplies all367 BTO labels. The existing merge fix also recovered eight EC names. The final LPSN production-path replay consumed35,425 cached API records without live calls or errors. Focused validation:88 LPSN tests and151 BTO/PREGO/freshness/dependency tests passed.

Read-only review findings #1837/#1838 were filed and fixed: validate API payload identity before attribution and bind actual record bytes/selected cache locators through immutable snapshots and a required admission audit. Final repository gates and the follow-up review are reported with the exact candidate below.

Further review findings #1839/#1840 were filed and fixed: LF-only audit serialization and an independent reconstruction of required records from verified GSS/API inputs. Coordinated-omission regressions and the fresh canary pass; graph hashes are unchanged.
