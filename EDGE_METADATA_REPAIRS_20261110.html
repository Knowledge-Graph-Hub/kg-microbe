Source-backed metadata repairs for EdgeMech

This change addresses #1834 and #1835, upstream follow-ups to EdgeMech #36. The retained graph inventory has 79,573 distinct nodes with missing labels. These repairs preserve identifiers, categories and associations.

LPSN publication nodes now use a unique nonempty publication_text or ijsem_list_text citation as their display name. The description records the source field and explicitly distinguishes a citation label from a verified article title. Conflicting citation strings remain unresolved; record order cannot select the winner. Blank or malformed values do not become labels.

PREGO now consumes the existing BTO SemSQL download as a fingerprinted metadata input. It hydrates only emitted BTO identifiers with explicit class declarations and unambiguous labels, preserves obsolete status and emits a mandatory metadata audit. Missing classes/labels remain unresolved. Malformed authority, changed bytes, redirected input locators and altered audits fail validation. Dictionary synonyms are not treated as authoritative names.

Each real canary followed the same launcher, environment and output path conventions as its subsequent replay, and persisted outputs were checked. The BTO canary caught a relative-path SQLite URI error; it was fixed and re-canary-tested before the 367-ID run. The LPSN canary caught an import resolving to the old checkout; PYTHONPATH=. and the recorded producer module verified the corrected path before the full-cache replay.

Read-only adversarial review found #1837 (unchecked API payload identity) and #1838 (API citation records absent from production freshness). Both were filed before correction. Cached/live payloads now require the requested ID. Production parses immutable record snapshots and records GSS selection plus every selected API cache locator in a mandatory lpsn_api_records.tsv. Finalization/admission reject changed or deleted consumed bytes, redirected selected locators and a missing or changed audit. Newly fetched responses are atomically cached before snapshot parsing; an initially empty cache remains supported.

The final offline production replay exercised run/_fetch, not only emitters. It consumed 35,425 cached API records, recorded 665 absent selected API paths and made zero live fetches with zero errors. Cached web-fallback labels remain outside this API-specific provenance guarantee. Canned empty responses for cache misses are a local replay constraint, not evidence of a remote API result. The earlier emitter-only artifacts remain retained but are superseded by this production-path receipt for validating the new record binding.

The final review additionally filed #1839 and #1840. Audit/GSS TSV writers now use LF-only serialization. Saved admission reconstructs required records from verified GSS roots and API links using the producer’s order, visited set and depth limit; it rejects coordinated omissions and extra inventory entries even when metadata and audit hashes are edited consistently. The new focused suites passed 59 transform/selection tests and 162 identity/TSV-contract tests (one existing test skipped because default-directory transformed outputs are absent). A fresh v3 canary preserved graph hashes and produced an LF-only audit. The final full replay uses lpsn-production-full-v3/receipt.json; its outcome and exact digest are reported on the PR. These are component and source-cache coverage checks, not a complete LPSN/PREGO source-release selection, complete merged graph or release regeneration. The historical EdgeMech release remains unchanged. Current upstream code also contains explicit ENVO dispositions; it should be used during normal regeneration rather than duplicated. IMG and INSDC still lack owner-supplied record titles in these inputs. Partial and obsolete EC semantics remain tracked in #267/#268, and citation conflicts require source reconciliation. These gaps are not evidence that their biological edges are false.

Final gates use an isolated Python3.12 Poetry environment installed from the lockfile. The initial focused tests used Python3.10 with an explicit checkout import path.
