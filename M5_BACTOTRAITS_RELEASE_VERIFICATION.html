Adversarial guard follow-up, 2026-11-19

The subsequent independent review recorded three additional defects in #1874, #1875 and #1876, and identified the remaining permitted-write requirement in #1870.

The production launcher now binds the child package and CLI module to its selected checkout instead of accepting ambient Python import routing. It copies retained inputs privately, verifies their complete identities, then publishes them without overwriting a competing target. An interrupted copy retains private failure evidence without publishing a truncated canonical input.

New production plans and receipts use bactotraits-production-unit-v2. Declare each permitted raw derivative using repeatable --allow-raw-write PATH options; paths are exact and relative to the isolated task’s raw directory. The launcher inventories nested raw entries and records additions, changes and deletions. An undeclared effect fails the unit and retains a failure diagnostic. A permitted raw effect does not establish producer finalization, scientific acceptance or release readiness.

The bounded finalizer also checks the preceding candidate’s complete code inventory and consumed identity-policy path and SHA256 against the current plan. Matching Git revisions alone do not establish matching code or policy when a candidate replay permits local changes.

The original M5 plans, receipts, graph counts and hashes above describe their original executions. They remain historical evidence and are not relabeled as runs of these new guards. Validate the new helper on one actual unit before a larger production run. Source freshness, downstream completion and publication gates remain in force.
