# BacDive publication-shape fixtures

Synthetic records using BacDive's `Reference`, `@id`, `@ref`, and metabolite-utilization structure. The `10.1234/...` DOI values are test identifiers, not literature claims. Fixtures exercise both record shapes, string/integer reference keys, opposite utilization outcomes, distinct papers supporting the same assertion, an unresolved pointer, and an unrelated paper that must not appear on any emitted assertion.
