# Native GOLD taxonomy witnesses

`native_contexts.json` is a bounded, immutable extraction of eight actual
GOLD referents from the selected source snapshot. It preserves complete
native node/edge columns, original physical line coordinates, source file
SHA-256 bindings, and separately labelled historical transformed rows.

The producer tests select the eight native declarations, their exact native
`in_taxon` statements and target declarations. This excerpt is not a complete
GOLD export, does not assert that its local line numbers equal full-export
coordinates, and supplies no invented positive strain evidence. Source study
and environment contexts remain available in the fixture as evidence, not
new retained graph assertions.

The eight include explicit metagenome/binned-genome records, other named
unverified referents, and the real blank-name `gold:Go0531699`. Names and
NCBITaxon xrefs cannot establish the named-strain convention in issue #834.
Issue #1316 therefore retains these source referents without a taxon identity
claim.

`fold_native_contexts.json` is the independently reviewed restoration excerpt:
six actual source IDs, 25 complete native declarations, 16 native incident
assertions, 10 ecosystem parent assertions, four selected NCBITaxon rows and
one literal `merged.dmp` remap witness. Full-source input digests and original
physical coordinates are retained separately from the local fixture's row
coordinates. Two records share a native environment observation previously
deduplicated after folding; a root-only habitat remains excluded; one record
has no habitat; and Study claims remain audit context rather than new graph
assertions. This is not the complete export and is not strain-identity evidence.
The producer preserves these original record IDs and observations. Historical
normalized label equality is now diagnostic only, in the mandatory restoration
audit, never a source-record-to-taxon identity replacement.

`microbedecoder_native_context.json` preserves complete native CSV record 3
and the full selected GOLD declaration/parent witnesses for `gold:Go0009048`.
It is evidence for the original crosswalk observation, not evidence that the
LPSN and GOLD referents are identical (their displayed taxonomic names differ).
The bounded dispatcher test makes no whole-producer freshness claim and does
not invent a new accepted strain or repair the source's claim.
