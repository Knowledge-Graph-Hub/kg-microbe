# Source-report fixtures

Synthetic offline rows distinguish finalized edge multiplicity from producer
report counts. Equal labels retain different IDs, categories and source fields;
identical MetaTraits report rows retain multiplicity and their observation
counts. The edge description begins with a literal quote because KGX TSV input
uses `QUOTE_NONE`; producer report TSVs use ordinary CSV quoting.

These rows do not assert chemical identities or interpret the source values.
