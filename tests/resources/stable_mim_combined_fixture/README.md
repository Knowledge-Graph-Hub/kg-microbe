# Genuine tiny native combined fixture

This constructor is test-only. It uses MediaIngredientMech
68bba8a68c79049e7602e4b10a12b1baf700d840 and a separately selected maintained
Python 3.13 interpreter. It checks the complete selected upstream package and
fixture members against that commit before importing any MIM code and rechecks
their hashes after native generation.

The source data, identities, review evidence and reviews are synthetic. Two
supported water source cases coexist with context-only and identity-held CM
cases and a small withheld KG cohort. No claim about real material identity,
current MIM generation, certified final products, or release acceptance follows.

The CM path uses the pinned upstream tests/culturemech_replay_fixture.py.
Its one-recipe archive is tests/fixtures/native_cm_v3_replay/cm-producer-code.tar.gz
(SHA256 d927bf794cd4e400e7a1aebed7b13cace860a3d8c2c5b4d1e947a031cd981fbc).
The genuine archived CM bundle build and verify, historical preparation, and
historical reviewed finalization run in the newly created test root.
Expected CM counts are two positive inventory rows, one context-only row, one
held row, two supported historical binding cases and two withheld cases.

KG literal graphs/ledgers start from the pinned upstream combined_fixture
construction. Its fake CM package is discarded in memory and replaced by the
new genuine package. A new private KG Git root commits the synthetic prior pin;
the frozen graph witnesses, row ledgers, prior partitions, transport and source
selector are constructed together. Old/global coordinates remain distinct from
the new combined physical positions. Historical original obligations remain
explicitly unresolved rather than acquiring guessed new owners.

The source assembler generates the tables from authenticated selected originals.
Fresh native inspect_candidates targets and separate primary/skeptical reports
retain the exact full input union. Actual export_candidate, validate_candidate
and historical CM replay reconstruct products before all three capabilities
can appear. The constructor never amends a manifest to add the capability.

Use only an empty output path under pytest tmp_path or the owned durable task
data directory. Supply exact producer, runtime, upstream fixture and constructor
hashes. Invoke with Python -I -B. The external package/runtime selectors are
never inferred from an active MIM campaign. Companion absence is explicit;
existing native controls cover required companion mode.

The native-only constructor does not reconcile the historical-to-current owner transition:
the historical Water record has no permanent MIM ID, and the fresh current
Water record does. KGM final integration must separately validate a reviewed
transition reconciliation with exact old/new payload, owner and review bindings.
A native constructor success is therefore not final integration acceptance.

Provenance: derived from the pinned upstream tests/test_source_bindings.py,
tests/culturemech_replay_fixture.py and tests/test_combined_source_conservation.py,
and their source conservation/assembly contracts. Upstream BSD-3-Clause terms
remain applicable; see the upstream LICENSE retained in the pinned checkout.

The explicit --review-transitions variant constructs a separate synthetic ledger
from complete actual historical binding rows and review decisions plus actual
native inspected payloads. All four CM cases change owner bytes or become
ownerless while remaining withheld. The ledger and captured synthetic source
evidence become native request inputs and enter both scientific report input
unions. Each affected identity assessment binds the complete entry SHA256 and
references both captures. The variant does not grant approval to any real
historical owner transition; KGM must still validate the ledger and native
reports before synthetic final-route qualification.

The explicit request union includes every package.json inventory member, including
historical capsule copies not needed by native execution. This closes #1894;
minimal replay success alone does not satisfy complete final package admission.
