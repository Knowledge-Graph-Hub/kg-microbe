# Finite UPA reaction-context review fixtures

These are faithful excerpts of the pinned native UPA JSON, UPA OWL and selected
GO SemSQL authority, not a miniature replacement ontology. `origin.json` identifies
the complete original inputs and the distinct excerpt bytes. The seven policy
records preserve complete native declarations, reaction/step/pathway premises,
literal XML and explicit original/current GO identities. All 1,157 selected SQL
statement occurrences are retained, including metadata used by the existing GO
resolver and explicitly required replacement-chain declarations.

JSON positions in the original full input are zero-based. The historical
UPA42 evidence recorded path edge ordinals one-based; policy records retain both
conventions explicitly. Actual tiny-run audit coordinates are calculated from
the consumed excerpt and are never presented as full-file positions. JSON and
SQL fixtures are decoded scientific evidence, not claims of original lexical
JSON bytes, physical SQL locations, or historical producer consumption. Selected
OWL class stanzas are literal upstream bytes enclosed in the original namespace
declarations for a parseable excerpt.

The active fixture explicitly repins only complete-file hashes to the separately
identified excerpt files. All seven scientific rules, native record content and
finite identity guard remain unchanged. It builds a real SQLite authority and
runs the real converter, legacy writer, source finalizer and public admission;
only the external GO database bootstrap is replaced by the already-populated
local fixture database. Output and xref export paths are test-owned temporary
directories. The inactive fixture separately consumes the genuine policy and
creates a zero-cohort checkpoint without requiring native UPA or GO files.

Two additional, saved native routes provide positive conservation controls:
one direct weak xref and one unchanged legacy computed row. Their complete
native records, coordinates and historical rows are in `positive_route_origins.json`.
Retention in a compatibility test does not scientifically approve that computed
claim; it proves that the finite seven-rule screen is not a global GO exclusion.

This package does not approve the other 449 historical computed claims or add
any of the 1,958 missing candidate edges. Complete candidate enumeration is an
audit, not a scientific acceptance or graph-promotion operation.

The complete candidate inventory has twelve native GO spellings for the seven
reviewed route/canonical-target decisions: seven historical selected xrefs,
three explicit current IDs, and two further historical annotations. UER00879
xref position 6 contains GO:0043840, explicitly replaced by GO:0004084;
UER00134 xref position 2 contains GO:0018271, explicitly replaced by GO:0004077.
Both native SQL replacement records are already present in the immutable
fixture. These two annotations are not last-xref writer selections. The prior
ten-spelling completeness statement was incomplete; no new policy or graph
selection is introduced by correcting that count.

The actual converter runs in a fresh offline interpreter using the existing
complete, origin-pinned Biolink 4.4.2 model, predicate map and attributes under
